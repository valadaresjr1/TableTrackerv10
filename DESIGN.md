# Table Tracker — Midnight workspace
Original product UI for live poker notes, not a marketing page. The utility must remain usable one-handed and offline.

## Reference synthesis
- Linear: flat surface hierarchy, restrained borders, intentional accent, compact data UI.
- Raycast: quick-action controls, high contrast, economical rows and keyboard focus.
- Mercury: coherent day/night palette, calm type hierarchy and restrained elevation.

No third-party interface, logo, artwork, font download, analytics, or external dependency is copied or required.

## System
System sans with optional locally installed Inter; 4px spacing rhythm. Controls use 8px radii, grouped surfaces 12px, main panels 18px. Primary action blue, gold only for Hero, green for storage and notes status. Every theme has its own canvas, panels, borders, foreground, felt and rail. Original vector mark and poker felt are CSS/SVG, not image assets.

Desktop shows a table workspace alongside a dense player notebook. Mobile prioritizes the table with profiles below it. Native dialogs share a consistent hierarchy and scroll behavior. Settings have three user-selected sections. Animations are brief entry and interaction feedback, fully disabled with reduced-motion preferences. No automatic motion or external requests.
